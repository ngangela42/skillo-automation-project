## Test case 1: Positive: User can logout successfully

**Description** : Verify that a user can logout after successful login.
**Preconditions"**: The Home page is accessible.
**Steps**:

1. Navigate to the login page.
2. Fill in the correct username or email and correct password.
3. Click the Sign in button.
4. While on Home page, navigate to logout button from upper right side of the page.
5. Click the logout button.
   **Expected result**: The user is automatically redirected to login page.
